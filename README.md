How to add a new menu compoenent:
How This Works Now:
✅ What Happens:
Add new menu items to company.js with status: 'coming-soon'
No need to create files - the * route catches all undefined paths
ComingSoon component displays for any missing page
Menu items work - they just show "Coming Soon" page
✅ Benefits:
No broken links - everything works
Professional appearance - users know content is coming
Easy to add pages - just create the component and add a specific route
Template-friendly - works for any company
✅ To Add a Real Page Later:
Create the component (e.g., Activities.js)
Add the route in App.js
Update the menu item status to 'active'
Now you can add as many menu items as you want in company.js without worrying about creating files! 🚀
